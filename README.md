# lichen

**L**2s **I**n **CH**annels, **EN**forced on Bitcoin.

A layer 2 ledger whose tokens a hub issues, each user's holdings up to a cap collateralised in her own contract with the hub, and withdrawable on Bitcoin without trusting the hub for anything: not its honesty, not its liveness.

-------

CAVEAT: Do not use with real money. Most importantly, the code is unaudited either by humans or LLMs, almost all written by one LLM (extensively *tested* but not *audited*).

This README and the [main design paper](./papers/lichen-v0.5.0.pdf) are written by me. Most of the lower level documentation and instructions are LLM generated.

*Want to try it* - with a wallet, against a hub someone is running: go to the other repos in this org that describe prototype L2s built from lichen: [gLichen](https://lichenbtc-org/glichen) and [vLichen](https://lichenbtc-org/vlichen) for instructions and details on how they work.
